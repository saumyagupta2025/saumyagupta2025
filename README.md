## `> about`

I'm a Machine Learning engineer with hands-on experience across the **full ML lifecycle** — from data pipelines and model development to deployment and production monitoring.

My current edge: I specialize in **AI Evaluation & Observability** — the layer that most teams neglect until something goes wrong in production. I build systems that measure *what matters*, trace *why models behave the way they do*, and benchmark *whether improvements are real.*

- 🧠 **ML & Data Science** — classification, regression, NLP, feature engineering, model development
- 🤖 **LLM & GenAI Engineering** — RAG pipelines, agentic workflows, prompt engineering, fine-tuning
- 🔬 **AI Evaluations** — automated evals, hallucination detection, faithfulness & coherence metrics
- 📡 **Observability** — LLM tracing, latency profiling, retrieval quality monitoring
- 📊 **Benchmarking** — reproducible evaluation suites for RAG, agents & multimodal systems
- 🌱 **Currently deepening** — Agentic AI architectures, Multimodal RAG, production MLOps
